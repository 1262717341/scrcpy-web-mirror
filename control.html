使用指南

一、快速开始

  1. 手机打开「开发者选项 → USB 调试」，用数据线连接电脑。
  2. 点左侧「连接 → 开始 USB 投屏」，手机上点「允许」授权；出画面后即可触控。
  3. 无线投屏：手机与电脑连同一个 Wi‑Fi，先插 USB 点「开启无线调试」，拔线后填「IP:端口」点「连接」；也可点「自动搜索」。
  4. 连接成功后可切到「全屏」或「沉浸」，把画面放到最大。
  5. 结束时点「停止投屏」；想连本地服务一起关掉，点「停止服务」。

二、连接方式与排查

  • USB 投屏：最稳、延迟最低。可在「已授权设备」下拉里选具体设备；点「刷新」重新读列表，点「添加」授权新设备。开始前会自动让出本机 adb server，避免「设备正在被其他程序使用」；USB 投屏期间应用面板没有缓存的应用会先显示包名。
  • 无线投屏：地址格式为 192.168.1.100:5555。「自动搜索」会扫描同一网段的 5555 端口；「断开」只断当前无线会话。
  • 开启无线调试：首次必须先用 USB 连一次，工具会自动切到无线模式；成功后可以拔线。
  • 提示设备被占用：先关掉其它 adb 窗口、手机助手、其它投屏页面，再点重试；本工具开始 USB 投屏时会自动执行一次 adb kill-server。USB 与无线不要同时开。
  • 断线：舞台出现「连接已断开」时点「重新连接」；无线断线后工具会短暂重连一次，清理手机端残留进程并恢复声音。
  • 无线凭据：浏览器会按网址保存 ADB 授权；换端口或换浏览器需要重新授权一次。

三、画面参数与投屏设置

  • 分辨率：1280 适合大多数手机；越高越清晰也越吃带宽，原始分辨率负载最高。
  • 帧率：60 最均衡；120 需要手机和高刷屏支持；30 / 15 适合弱网省带宽。
  • 码率：8 Mbps 默认；画面糊可升到 16 / 32，卡顿则降到 4 / 2。
  • 视频源：屏幕镜像 / 前摄像头 / 后摄像头，切换后重新连接生效。
  • 声音输出：手机 + 电脑（推荐，Android 13+）、仅手机（电脑无声）、仅电脑（投屏期间手机静音）。
  • 保持唤醒：投屏期间把手机「自动锁屏时间」临时改成最大值，并主动点亮一次；正常停止投屏会恢复原值。若直接关页面、杀进程或断网，恢复命令可能来不及发出，下次连接同一设备会自动补恢复。
  • 启动时关闭屏幕：连接成功后立刻让手机熄屏，画面仍可投；关闭投屏时熄屏：停止时顺手锁屏。
  • 显示触摸点：在手机上显示触控落点，方便演示和录屏。
  • 以上选项都会自动保存，下次打开沿用。

四、画面操作与快捷键

  • 画面支持单击、长按、拖动、双指缩放和多点触控；鼠标滚轮会作为手机上的滚动事件发送。
  • 点画面后可直接用电脑键盘打字，字母、数字、退格、回车都会同步到手机；中文建议用「文本输入」或中文输入插件。
  • H 全屏 / 退出全屏；M 声音开关；I 或 V 进入 / 退出沉浸；Esc 退出沉浸；Shift+Esc 停止投屏。
  • 沉浸：隐藏工具轨和所有抽屉，只留画面；顶部出现「退出沉浸」提示，按 I / V / Esc 恢复。
  • 全屏：进入浏览器全屏并隐藏侧栏，右下角出现可拖动的浮动控制条；点标题栏可收起 / 展开，点「×」隐藏。

五、控制抽屉：导航与系统键

  • 导航：返回、主页、多任务、菜单。
  • 系统：电源（锁屏 / 亮屏）、音量加、音量减、亮屏、熄屏、旋转、通知栏、收起通知栏、控制栏、手机截屏、电脑截屏。
  • 画面旋转：左旋、回正、右旋，只影响网页里的显示方向，不改手机系统方向。
  • 手机截屏：调用手机截图并存到手机相册，适合需要原图时使用。
  • 电脑截屏：截取当前投屏画面，保存到电脑「图片」文件夹并自动打开；左侧「截屏」按钮也是同一功能。

六、文本输入与中文

  • 「文本输入」框输入即自动上屏；退格、回车会同步到手机。
  • 发送：把当前文本整段提交；复制：读取手机当前输入框内容；粘贴：把电脑剪贴板内容写进手机输入框。
  • 中文输入插件：约 18KB 的 ADB 输入法，直接把中文 commit 到手机输入框，不依赖剪贴板。首次发送中文时可点「安装中文输入插件」；勾选「连接时自动安装并启用」后每次连接自动切换。
  • 不想用了点「恢复手机输入法」，手机会切回原来的输入法。
  • 剪贴板同步：「电脑 → 手机」把电脑剪贴板贴到手机；「手机 → 电脑」把手机剪贴板复制到电脑。部分系统会限制后台读取剪贴板。

七、应用管理

  • 打开「应用」会自动读取手机应用列表；点「刷新」重新读取。
  • 筛选：全部显示 / 第三方应用 / 系统应用；搜索框支持应用名和包名。
  • 单个应用：点「启动」打开；点「停止」强制结束。第三方应用显示「卸载」，系统应用不显示卸载按钮，避免误操作。
  • 点应用名（包名）可查看版本、安装时间、签名等详情。
  • 安装 APK：点「安装 APK」从电脑选包，或把 APK 直接拖进应用面板；推送后调用 pm install，完成后刷新列表。
  • 多选与批处理：点「多选」进入勾选，或普通模式直接点应用行单选；顶部常驻「已选 N 项 / 全选 / 强行停止 / 停用 / 启用 / 清除数据… / 卸载… / 完成」。
  • 「全选」只作用于当前筛选结果；批量操作逐条执行，进度和失败原因写进日志。
  • 选中项含系统应用时，「卸载…」会禁用；系统应用只能停止、停用、启用或清除数据，不提供卸载。
  • 「完成」退出多选并清空选择；「清除数据…」和「卸载…」都会二次确认。

八、文件管理

  • 路径：可直接输入绝对路径回车打开；「↑」上一级；快捷入口有内部存储、下载、图片、相机、音乐、影片。
  • 新建 / 刷新 / 上传：在当前目录新建文件夹、刷新列表、从电脑选文件上传；也可把文件直接拖进文件面板上传到当前目录。
  • 点文件夹进入下一级；点文件选中并弹出名称、类型、大小、修改时间、完整路径。
  • 多选：点「多选」进入勾选，或普通模式直接点文件单选；批处理条有「已选 N 项 / 全选 / 详情 / 复制 / 粘贴 / 删除 / 取消」。
  • 复制：把选中项放进文件剪贴板，随后自动清空勾选并退出多选；切到目标目录点「粘贴」即可，跨目录保留。
  • 粘贴：同名文件自动生成「a - 副本.txt」；文件夹不能粘贴到自身或自己的子目录。
  • 删除：文件和文件夹可混合多选，二次确认后删除；文件夹会连同内部内容一起删除。
  • 取消：清空文件剪贴板并退出多选，适合复制后不想再粘贴时使用。
  • 把 APK 拖进文件面板会直接安装；其它文件只上传，不会自动安装。
  • 文件剪贴板只存在当前页面内存，刷新页面会清空；同一页面内跨目录粘贴正常。

九、状态与日志

  • 实时指标：丢帧、总帧数、视频编码、音频状态。
  • 实时日志：连接、参数、触控、应用、文件、截屏、异常都会逐条记录；点「清空」清除当前日志。
  • 侧栏底部读数条显示分辨率、帧率、设备序列号、声音状态和当前视图；它会跟随侧栏左右移动。
  • 连接异常时先看日志最后几行，通常会直接给出失败原因。

十、外观与布局

  • 皮肤预设：暖钨、薄荷、钴蓝、石墨，一键切换强调色和背景。
  • 自定义：可单独改强调色、背景色，修改即时生效。
  • 侧栏位置：左侧 / 右侧，工具轨和抽屉一起移动。
  • 外观设置保存在本机，点「恢复默认外观」还原。

十一、停止、重连与清理

  • 停止投屏：结束 scrcpy、释放音频、恢复手机息屏时间，网页保留可重新连接。
  • 停止服务：结束投屏后关闭本地 Python 服务并关闭页面；下次运行 start.vbs 重新启动。
  • 断线清理：手机端看门狗在失联超过约 30 秒或 Wi‑Fi 地址消失时，自动结束 scrcpy、释放音频。
  • 若手机仍无声，按一次手机音量键，或重新连接一次投屏。

十二、常见问题

  • 画面黑屏 / 无画面：确认手机已解锁、USB 调试已授权；无线时确认 IP 没变、端口 5555 未被占用。
  • 卡在「ADB 握手中」：多为浏览器没有该网址的 ADB 凭据，或 adb 被其它程序占用；换回原来能连的端口 / 浏览器重新授权。
  • 中文打不进去：点「安装中文输入插件」，或改用「文本输入」框整段发送。
  • 文件复制后勾选消失：这是正常行为，复制已结束本次多选，剪贴板仍在，直接去目标目录粘贴即可。
  • 系统应用没有卸载按钮：系统应用默认不提供卸载，避免破坏系统功能。
  • 浏览器要求：请用 Edge / Chrome 等 Chromium 内核浏览器，旧版 IE 不支持 WebUSB 和投屏。
